# quantagen-bench results

Generated by `python bench/report.py` from `bench/corpus.json` and the hash-verified files in `bench/cache/`. Nothing in this file is edited by hand; a number that cannot be regenerated is not quoted.

Token counts use `tiktoken` (gpt-4o). Retrieval is BM25 over 120-word chunks with 30-word overlap, averaged over three window alignments. Retention is measured against the raw PyMuPDF text of the same document, so a tool that deliberately drops page furniture or references scores lower on numbers and entities — that cost is shown here rather than excused.

Wall clock is measured but excluded from this file: a timing that changes between two runs of the same code would make every row unquotable. Run `python bench/report.py --timings` for the cost table.
